# AI Editor for Premiere Pro: downloads

Releases of [CTTP AI Editor](https://cuttothepoint.gumroad.com/), the Premiere Pro panel that transcribes your timeline and lets AI pick the moments worth keeping.

**[Download the latest version](https://github.com/cttp-filmmaker/cttp-ai-editor-releases/releases/latest)**: open **Assets** on the release page and download the `.zxp` file.

## Install or update

1. Close Premiere Pro.
2. Open the `.zxp` with [ZXP Installer](https://aescripts.com/learn/zxp-installer/). If it asks, choose to install for the current user.
3. Start Premiere Pro and open **Window > Extensions > AI Editor**.

An update installs over the previous version and keeps your API keys, settings and presets. The panel tells you when a new version is out.

## Trial and license

Every feature is free for 7 days, starting the first time you transcribe or edit. No card or email is needed. To keep using it, buy a license and paste the key from your receipt under **Settings > License**.

Questions: contact@cuttothepoint.com
